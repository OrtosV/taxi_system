# Интеллектуальная система прогнозирования спроса на поездки такси

**Разработка интеллектуальной прогнозно-аналитической системы прогнозирования пространственно-временного спроса на поездки такси с учётом внешних факторов**

## 1. Описание проекта

Проект представляет собой интеллектуальную прогнозно-аналитическую систему, предназначенную для прогнозирования количества поездок такси по географическим зонам Нью-Йорка с горизонтом прогнозирования один час.

Система объединяет исторические данные о поездках, погодные условия, информацию о дорожно-транспортных происшествиях и обращения жителей в городскую службу 311. На основе объединённого набора данных формируется пространство признаков, после чего обучаются и сравниваются модели машинного обучения.

Результаты прогнозирования отображаются в интерактивном веб-интерфейсе. Пользователь может выбирать дату и время, изучать пространственное распределение ожидаемого спроса, анализировать динамику отдельных зон и оценивать изменение прогноза при различных погодных условиях.

**Основной пользователь системы:** аналитик транспортных операций или специалист по распределению парка такси.

**Практическая задача:** определение зон с ожидаемым повышенным спросом для поддержки решений о распределении транспортных ресурсов.

## 2. Цель и задачи проекта

**Цель:** разработать воспроизводимую интеллектуальную систему прогнозирования пространственно-временного спроса на поездки такси с использованием методов машинного обучения и внешних данных.

Для достижения цели решаются следующие задачи:

- организация загрузки данных из нескольких разнородных источников;
- формирование единого исторического набора данных;
- очистка, проверка качества и пространственно-временное объединение данных;
- построение признакового пространства для прогнозирования;
- обучение и сравнение моделей машинного обучения;
- выбор итоговой модели по результатам временной валидации и тестирования;
- интерпретация прогнозов и анализ значимости признаков;
- разработка механизмов мониторинга качества и управления версиями моделей;
- создание интерактивного аналитического интерфейса.

## 5. Формирование целевой переменной

В качестве целевой переменной используется количество поездок такси, начинающихся в определённой географической зоне в течение одного часа.

Обозначим целевую переменную:

\[
y_{z,t} = \operatorname{count}(z,t),
\]

где:

- \(z\) — географическая зона Нью-Йорка;
- \(t\) — временной интервал продолжительностью один час;
- \(y_{z,t}\) — количество поездок, начавшихся в зоне \(z\) за час \(t\).

Задача модели — спрогнозировать спрос на следующий час:

\[
\hat{y}_{z,t+1} = f(X_{z,t}),
\]

где \(X_{z,t}\) — признаки, доступные на момент формирования прогноза.

После агрегации исторических поездок сформирована полная временная сетка:

- 263 географические зоны;
- 17 544 временных интервала;
- 4 614 072 наблюдения.

Специальные зоны `Unknown` и `Outside of NYC` сохраняются в исторических данных и модельном наборе, но исключаются из географической визуализации. На карте отображаются 261 зона с соответствующей геометрией.

## 6. Предобработка и формирование признаков

После загрузки источников выполняется проверка структуры данных, типов полей, пропусков, дубликатов и корректности временных отметок.

Далее данные объединяются по временным интервалам и географическим зонам.

Для модели сформировано 47 признаков, которые можно разделить на несколько групп.

### Временные признаки

- час прогнозируемого интервала;
- день недели;
- день месяца;
- месяц;
- признак выходного дня;
- циклические представления часа и дня недели через синус и косинус.

# Выбор финальной модели

## 1. Цель сравнения

Целью этапа являлся выбор модели прогнозирования почасового спроса на поездки такси по зонам Нью-Йорка.

Сравнение выполнено на тестовой выборке, содержащей 685 641 наблюдение.

Для оценки использовались пять метрик: MAE, MSE, RMSE, WAPE и R².

## 3. Выбор финальной модели

В качестве финальной модели выбрана **XGBoost**.

Идентификатор эксперимента: `exp_20261110_153017`.

Исходная конфигурация XGBoost показала лучший результат по всем пяти метрикам на тестовой выборке.

Показатели финальной модели:

- MAE: 4.2014
- MSE: 142.0940
- RMSE: 11.9203
- WAPE: 18.8247%
- R²: 0.9638

## 4. Сравнение с базовой моделью

В качестве базового алгоритма использовалась Seasonal Naive.

MAE базовой модели: 6.8421.
MAE XGBoost: 4.2014.

Относительное снижение MAE составило 38.59%.

## 5. Обоснование выбора

Исходная модель XGBoost продемонстрировала более высокое качество на тестовой выборке, чем остальные рассматриваемые алгоритмы, включая их настроенные версии.

Настройка гиперпараметров улучшила результаты XGBoost на валидационной выборке, однако не обеспечила аналогичного улучшения на тестовой выборке. Поэтому для дальнейшей разработки выбрана исходная конфигурация.

Тестовая выборка ранее просматривалась в ходе первоначального сравнения моделей. Поэтому её нельзя считать полностью нетронутой контрольной выборкой. После данного этапа тестовые результаты не используются для дальнейшего подбора гиперпараметров.

## 6. Дальнейшее использование

Выбранная модель будет использоваться для разработки интерпретации прогнозов, прогнозного модуля и пользовательского интерфейса системы.
